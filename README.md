# crop-health-checker
A beginner C project that checks crop conditions and provides basic recommendations.

## About the Project

This program takes basic information about a crop and its growing conditions and gives suitable suggestions.

## Parameters

- Crop type
- Soil type
- Moisture level
- Leaf color
- Growth condition
- Pest presence
- Soil pH

## Technologies Used

- C Programming
- VS Code

## Project Goal

To create a simple beginner-friendly program to understand crop health conditions using C programming.
